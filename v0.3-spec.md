# CAS Extractor v0.3 Spec — obj.method() Type-Inference

**Scope**: Lightweight, high-precision heuristics only
**Goal**: Reduce unresolved PYFUNC by 20-40% without false positives
**Non-Goal**: Full type inference, cross-module data flow

---

## Baseline (v0.2)

From httpie golden test:
- unresolved PYFUNC targets: 63 (10.8% of R5 findings)
- Total call edges: 2,810
- Resolution rate: ~65% (deduped relations / total edges)

---

## Heuristic Rules (High Precision Only)

### H1: Local Variable → Constructor → Method Call

**Pattern**:
```python
def foo():
    x = SomeClass()  # or x = SomeClass(arg)
    x.method()       # → resolve to SomeClass.method
```

**Conditions**:
- Assignment in same function scope
- Right-hand side is a Call with Name matching a known class
- Class has method with matching name
- **Confidence**: E2 (heuristic, intra-scope)

**Implementation**:
1. Track local variable assignments in function scope
2. If RHS is `Name(args)` and Name is a class in current module → record {var: class}
3. On `obj.method()` call: if obj in var-map → resolve to `Module.Class.method`

---

### H2: Self-Attribute Assignment in __init__

**Pattern**:
```python
class Foo:
    def __init__(self):
        self.bar = OtherClass()
    
    def do_something(self):
        self.bar.method()  # → resolve to OtherClass.method
```

**Conditions**:
- Assignment in `__init__` method
- `self.attr = ClassName(...)` where ClassName is known class
- Later `self.attr.method()` in same class
- **Confidence**: E2 (heuristic, intra-class)

**Implementation**:
1. Track `self.attr = ClassName(...)` assignments in `__init__`
2. Store in class context: {attr: class_name}
3. On `self.attr.method()` call: lookup in class context

---

### H3: Direct Class Instantiation Method Chain

**Pattern**:
```python
SomeClass().method()  # → resolve to SomeClass.method
```

**Conditions**:
- Call on result of constructor
- Class has method with matching name
- **Confidence**: E1 (structural, no scope tracking needed)

**Implementation**:
1. Detect `Call(func=Name(...)).method()` pattern
2. If func.Name is a class → resolve directly

---

## Non-Goals (Explicitly Out of Scope)

| Pattern | Reason |
|---------|--------|
| Cross-module type flow | Too complex for v0.3 |
| Return type inference | Requires interprocedural analysis |
| `x = func_returning_obj()` | Can't determine return type statically |
| Dynamic dispatch (`getattr`) | Impossible without runtime |
| Subclass polymorphism | Requires full class hierarchy analysis |
| Third-party library types | No type stubs in v0.3 |

## Test Cases

### H1 Tests

```python
# TC-H1-1: Basic local var resolution
def test_h1_basic():
    client = HTTPClient()
    client.request()  # Should resolve to HTTPClient.request

# TC-H1-2: Multiple assignments - last wins
def test_h1_shadow():
    x = ClassA()
    x = ClassB()
    x.foo()  # Should resolve to ClassB.foo (last assignment)

# TC-H1-3: Nested scope - no resolution
def test_h1_nested():
    x = ClassA()
    if condition:
        x = ClassB()
        x.foo()  # Should resolve to ClassB.foo
    x.foo()  # Should resolve to ClassA.foo (outer scope)

# TC-H1-4: Unknown class - no resolution
def test_h1_unknown():
    x = external_lib.ClassX()
    x.foo()  # Should remain unresolved
```

### H2 Tests

```python
# TC-H2-1: Basic self.attr resolution
class Service:
    def __init__(self):
        self.client = HTTPClient()
    
    def run(self):
        self.client.send()  # Should resolve to HTTPClient.send

# TC-H2-2: Inherited attribute
class BaseService:
    def __init__(self):
        self.client = HTTPClient()

class DerivedService(BaseService):
    def run(self):
        self.client.send()  # Should resolve (if inheritance tracked)

# TC-H2-3: Attribute not in __init__
class Bad:
    def setup(self):
        self.client = HTTPClient()
    
    def run(self):
        self.client.send()  # Should NOT resolve (not __init__)
```

### H3 Tests

```python
# TC-H3-1: Direct chain
HTTPClient().request()  # Should resolve to HTTPClient.request

# TC-H3-2: Nested chain
get_factory().create().method()  # Should NOT resolve (factory unknown)
```
