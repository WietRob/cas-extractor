# H2.7 Scope Specification — Bounded Multi-Hop Self-Attr Propagation

**Feature-ID:** H2.7
**Sprint:** v0.4.3
**Status:** Specification

---

## Ziel

Erweitere H2.6-Resolution auf **Multi-Hop Propagation** über Helper-Ketten innerhalb einer Klasse: Wenn `self.a()` → `self.b()` → `self.c()` und `c` weist `self.attr = ClassName()` zu, propagiere den Typ zur aufrufenden Methode.

---

## Pattern-Definition

### H2.7 Positive Pattern

```python
class Example:
    def init_client(self):
        self.client = HTTPClient()  # Assignment at depth 2
    
    def prepare(self):
        self.init_client()           # Depth 1 from run
    
    def run(self):
        self.prepare()               # Entry point
        self.client.send()           # H2.7: HTTPClient.send via chain
```

### H2.6 vs H2.7 Comparison

| Pattern | H2.6 | H2.7 |
|---------|------|------|
| Direct helper: `run() -> helper() -> attr = Class` | ✅ | ✅ |
| Two-hop: `run() -> h1() -> h2() -> attr = Class` | ❌ | ✅ (if depth >= 2) |
| Three-hop chain | ❌ | ✅ (if depth >= 3) |
| Cross-class helper | ❌ | ❌ |
| Factory return | ❌ | ❌ |
| Cycle A↔B | ❌ | ❌ |

## In Scope

| Pattern | Status |
|---------|--------|
| Multi-hop helper chains within same class | ✅ IN |
| Bounded depth propagation (default: 2) | ✅ IN |
| Cycle detection + skip | ✅ IN |
| `Assign` + `AnnAssign` in any chain method | ✅ IN |
| Conservative merge (conflict → unknown) | ✅ IN |
| Configurable max chain depth | ✅ IN |

## Out of Scope

| Pattern | Status | Reason |
|---------|--------|--------|
| Cross-class propagation | ❌ OUT | Requires whole-program analysis |
| Factory return inference | ❌ OUT | Requires interprocedural analysis |
| Path-sensitive branch analysis | ❌ OUT | Too complex |
| Inter-file recursion | ❌ OUT | Scope limit |
| Dynamic dispatch | ❌ OUT | Not statically analyzable |

## Resolution Priority Order

1. **H2.5 method-local** (intra-method assignment)
2. **H2.7 transitive propagated** (from multi-hop helper chain)
3. **H2.6 single-hop propagated** (from direct helper)
4. **H2 class-level** (`__init__` assignment)

### Why H2.7 > H2.6

H2.7 is a superset of H2.6. When enabled:
- H2.7 handles multi-hop chains (including single-hop as depth=1)
- H2.6 logic becomes redundant but kept for backward compatibility
- Both use the same `self_attr_dispatch` resolution type

---

## Bounded Propagation

### Depth Definition

| Depth | Meaning |
|-------|---------|
| 0 | No propagation (disabled) |
| 1 | Direct helper only (equivalent to H2.6) |
| 2 | Two-hop: caller → helper → sub-helper (default) |
| 3+ | Deeper chains (higher FP risk) |

### Depth Cap Behavior

```python
class ChainExample:
    def level3(self):
        self.client = HTTPClient()  # Assignment at depth 3
    
    def level2(self):
        self.level3()                # Depth 2 from level1
    
    def level1(self):
        self.level2()                # Depth 1 from run
    
    def run(self):
        self.level1()                # Entry point
        self.client.send()
        # Depth 3 from assignment
        # With depth=2: UNRESOLVED
        # With depth=3: HTTPClient.send
```

## Cycle Detection

### Problem

```python
class CycleExample:
    def method_a(self):
        self.method_b()              # Calls B
        self.client.send()
    
    def method_b(self):
        self.method_a()              # Cycle!
        self.client = HTTPClient()
```

### Solution

H2.6 already has cycle detection via `visiting` set. H2.7 reuses this:
- Track `visiting` set during chain traversal
- If method already in `visiting`, skip (don't propagate through cycle)
- Cycle methods remain unresolved for self.attr

## Conflict Resolution

### Problem

```python
class ConflictExample:
    def setup_http(self):
        self.client = HTTPClient()   # Option 1
    
    def setup_ws(self):
        self.client = WebSocketClient()  # Option 2
    
    def init_http(self):
        self.setup_http()
    
    def init_ws(self):
        self.setup_ws()
    
    def run(self):
        self.init_http()
        self.init_ws()               # Both called
        self.client.send()           # client = HTTPClient or WebSocketClient?
```

### Solution

Same as H2.6: Same `self.attr` from different paths with **different types** → `None` (unknown)

### H2.7 Enhancement

H2.7 requires **transitive closure** computation:

```python
def _propagate_self_attr_summaries_transitive(
    class_node, initial_summaries, class_methods, max_depth=2
):
    """
    H2.7: Compute transitive closure of self.attr types.
    
    Algorithm:
    1. Build call graph: {caller: [callees]}
    2. For each method, compute reachable self.attr types
    3. Apply depth bound during traversal
    4. Detect cycles via visiting set
    5. Merge conflicts → None
    
    Returns: {method_name: {attr_name: class_qname | None}}
    """
```

### Key Differences from H2.6

| Aspect | H2.6 | H2.7 |
|--------|------|------|
| Propagation | Single-hop (direct helper) | Multi-hop (transitive closure) |
| Call graph | Built on-the-fly | Pre-computed per class |
| Depth control | Per-call recursion | Bounded traversal |
| Complexity | O(n) per method | O(n × d) where d = max_depth |
