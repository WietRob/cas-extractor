# H2.6 Scope Specification — Class-Local Inter-Method Self-Attr Propagation

**Feature-ID:** H2.6
**Sprint:** v0.4.2
**Status:** Specification

---

## Ziel

Erweitere H2/H2.5-Resolution auf **Inter-Method-Propagation** innerhalb einer Klasse: Wenn `self.helper()` aufgerufen wird und `helper` ein `self.attr = ClassName()` enthält, propagiere den Typ zu aufrufender Methode.

---

## Pattern-Definition

### H2.6 Positive Pattern

```python
class Example:
    def setup(self):
        self.client = HTTPClient()  # H2.6 anchor in helper
    
    def run(self):
        self.setup()                 # H2.6: detect self.setup() call
        self.client.send()           # H2.6 resolved: HTTPClient.send
```

### H2.6 vs H2/H2.5 Comparison

| Pattern | H2 (v0.4) | H2.5 (v0.4.1) | H2.6 (v0.4.2) |
|---------|-----------|---------------|---------------|
| `self.attr = Class()` in `__init__`, call in any method | ✅ Resolved | ✅ Resolved | ✅ Resolved |
| `self.attr = Class()` in non-`__init__`, call in same method | ❌ Unresolved | ✅ Resolved | ✅ Resolved |
| `self.attr = Class()` in helper, call after `self.helper()` | ❌ Unresolved | ❌ Unresolved | ✅ Resolved |
| `self.attr = Class()` in helper, call in different class | ❌ Unresolved | ❌ Unresolved | ❌ Unresolved |

## In Scope

| Pattern | Status |
|---------|--------|
| Class-local propagation (same class only) | ✅ IN |
| `self.helper()` call detection | ✅ IN |
| Bounded depth propagation (default: 2) | ✅ IN |
| Cycle detection + skip | ✅ IN |
| `Assign` + `AnnAssign` in helpers | ✅ IN |
| Last-assignment-wins in helper | ✅ IN |
| Conflict → unknown (conservative) | ✅ IN |

## Out of Scope

| Pattern | Status | Reason |
|---------|--------|--------|
| Cross-class propagation | ❌ OUT | Requires whole-program analysis |
| Factory return inference | ❌ OUT | Requires interprocedural analysis |
| Full MRO traversal | ❌ OUT | Complexity, FP risk |
| Dynamic dispatch / setattr | ❌ OUT | Not statically analyzable |
| Path-sensitive analysis | ❌ OUT | Too complex |
| Cross-module propagation | ❌ OUT | Scope limit |

## Resolution Priority Order

1. **H2.5 method-local** (intra-method assignment)
2. **H2.6 propagated** (from called helpers)
3. **H2 class-level** (`__init__` assignment)
4. **Unresolved/skip**

### Example

```python
class Example:
    def __init__(self):
        self.client = HTTPClient()      # H2 anchor
    
    def reconnect(self):
        self.client = WebSocketClient() # H2.5 anchor in helper
    
    def setup(self):
        self.reconnect()                 # H2.6: calls reconnect
    
    def run(self):
        self.client = HTTPClient()       # H2.5 in caller (wins)
        self.setup()                     # H2.6: calls setup -> reconnect
        self.client.send()               # H2.5 wins: HTTPClient.send
```

## Bounded Propagation

### Depth Cap

- Default: `2` levels
- Configurable via `--h26-max-helper-depth N`
- Depth 0 = disabled (H2.6 OFF equivalent)
- Depth 1 = direct helper only
- Depth 2 = helper -> helper -> caller (default)
- Depth 3+ = deeper chains (higher FP risk)

### Example Depth Behavior

```python
class ChainExample:
    def level1(self):
        self.client = HTTPClient()       # Anchor at depth 1 from level2
    
    def level2(self):
        self.level1()                    # Depth 1 from level3
    
    def level3(self):
        self.level2()                    # Depth 2 from run
    
    def run(self):
        self.level3()                    # Calls level3 -> level2 -> level1
        self.client.send()               # Depth 3 from anchor
        # With depth=2: UNRESOLVED
        # With depth=3: HTTPClient.send
```

## Cycle Detection

### Problem

```python
class CycleExample:
    def method_a(self):
        self.method_b()                  # Calls method_b
        self.client.send()
    
    def method_b(self):
        self.method_a()                  # Calls method_a (cycle!)
        self.client = HTTPClient()
```

### Solution

- Track `visiting` set during propagation
- If method already in `visiting`, skip (don't propagate through cycle)
- Cycle methods remain unresolved for self.attr

### Behavior

```python
# CycleExample with H2.6 ON:
# method_a calls method_b, method_b calls method_a
# Detection: method_a in visiting when method_b tries to call it
# Result: self.client.send() in method_a -> UNRESOLVED (cycle blocked)
```

## Conflict Resolution

### Problem

```python
class ConflictExample:
    def setup_http(self):
        self.client = HTTPClient()       # Sets client = HTTPClient
    
    def setup_ws(self):
        self.client = WebSocketClient()  # Sets client = WebSocketClient
    
    def run(self):
        self.setup_http()
        self.setup_ws()
        self.client.send()               # client = HTTPClient or WebSocketClient?
```

### Solution

- Same `self.attr` from different helpers with **different types** → `None` (unknown)
- Resolution: If propagated type is `None`, skip to next priority (H2) or unresolved

### Behavior

```python
# ConflictExample with H2.6 ON:
# setup_http sets client = HTTPClient
# setup_ws sets client = WebSocketClient
# Conflict detected: client has 2 different types
# Result: self.client.send() -> UNRESOLVED (conservative)
```

## Implementation Notes

### Data Structure Extension

```python
class ClassInfo:
    __slots__ = ("qname", "methods", "base_names", "self_attr_types", 
                 "method_self_attr_summaries")
    
    # method_self_attr_summaries: dict[str, dict[str, str | None]]
    # {method_name: {attr_name: class_qname | None}}
    # None = conflict detected
```

### Propagation Algorithm

```python
def _propagate_self_attr_summaries(
    class_info: ClassInfo,
    summaries: dict[str, dict[str, str]],
    max_depth: int = 2,
) -> dict[str, dict[str, str | None]]:
    """
    Propagate self.attr types through self.helper() calls.
    
    Returns: {caller_method: {attr_name: class_qname | None}}
    None indicates conflict.
    """
    propagated = {m: dict(attrs) for m, attrs in summaries.items()}
    visiting: set[str] = set()
    
    def propagate(method: str, depth: int) -> dict[str, str | None]:
        if depth > max_depth or method in visiting:
            return {}
        
        visiting.add(method)
        result = dict(propagated.get(method, {}))
        
        for call in get_self_calls(method):
            if call in summaries:
                callee_attrs = propagate(call, depth + 1)
                for attr, class_qname in callee_attrs.items():
                    if attr not in result:
                        result[attr] = class_qname
                    elif result[attr] != class_qname:
                        result[attr] = None  # Conflict
        
        visiting.remove(method)
        return result
    
    for method in summaries:
        propagated[method] = propagate(method, 0)
    
    return propagated
```

### Resolution Integration (Case 2d extension)

```python
# After H2.5, before H2:
if attr_name in propagated_self_attr_types:
    class_qname = propagated_self_attr_types[attr_name]
    if class_qname is not None:  # Not a conflict

        if ci and method_name in ci.methods:
```
