# H2.6 Flag Contract — Feature Flag Design

**Feature-ID:** H2.6
**Sprint:** v0.4.2
**Status:** Contract Definition

---

## Flag Overview

| Flag | Type | Default | ENV Variable |
|------|------|---------|--------------|
| `--enable-h26-self-attr-intermethod` | bool | `false` | `CAS_ENABLE_H26_SELF_ATTR_INTERMETHOD` |
| `--h26-max-helper-depth` | int | `2` | `CAS_H26_MAX_HELPER_DEPTH` |

---

## Primary Flag: `--enable-h26-self-attr-intermethod`

### Purpose

Enable/disable H2.6 inter-method self-attr propagation.

### Values

| Value | Behavior |
|-------|----------|
| `false` (default) | H2.6 disabled, use H2/H2.5 only |
| `true` | H2.6 enabled with default depth (2) |

### CLI Usage

```bash
# Enable H2.6
python3 extract_python.py \
  --enable-h26-self-attr-intermethod true \
  --repo-root . \
  --repo-name repo://main \
  --revision git:HEAD \
  --out ./evidence

# Disable H2.6 (explicit)
python3 extract_python.py \
  --enable-h26-self-attr-intermethod false \
  --repo-root . \
  --repo-name repo://main \
  --revision git:HEAD \
  --out ./evidence
```

### ENV Usage

```bash
# Enable via ENV
CAS_ENABLE_H26_SELF_ATTR_INTERMETHOD=true python3 extract_python.py ...

# Disable via ENV
CAS_ENABLE_H26_SELF_ATTR_INTERMETHOD=false python3 extract_python.py ...
```

### Precedence

```
CLI flag > ENV variable > Default (false)
```

### Help Text

```
  --enable-h26-self-attr-intermethod ENABLE_H26_SELF_ATTR_INTERMETHOD
                        Enable H2.6: resolve self.attr.method() where self.attr
                        is assigned in a helper method called via self.helper().
                        Propagates types through self.helper() calls within the
                        same class. (default: false, ENV: CAS_ENABLE_H26_SELF_ATTR_INTERMETHOD)
```

## Secondary Flag: `--h26-max-helper-depth`

### Purpose

Control maximum propagation depth for H2.6.

### Values

| Value | Behavior |
|-------|----------|
| `0` | H2.6 effectively disabled (no propagation) |
| `1` | Direct helper only (caller -> helper) |
| `2` (default) | Two levels (caller -> helper -> sub-helper) |
| `3+` | Deeper chains (higher false positive risk) |

### CLI Usage

```bash
# Depth 1 (conservative)
python3 extract_python.py \
  --enable-h26-self-attr-intermethod true \
  --h26-max-helper-depth 1 \
  --repo-root . \
  --out ./evidence

# Depth 3 (aggressive)
python3 extract_python.py \
  --enable-h26-self-attr-intermethod true \
  --h26-max-helper-depth 3 \
  --repo-root . \
  --out ./evidence
```

### ENV Usage

```bash
CAS_H26_MAX_HELPER_DEPTH=3 python3 extract_python.py ...
```

### Precedence

```
CLI flag > ENV variable > Default (2)
```

### Help Text

```
  --h26-max-helper-depth H26_MAX_HELPER_DEPTH
                        Maximum propagation depth for H2.6 inter-method analysis.
                        Depth 1 = direct helper only, Depth 2 = helper chain of 2
                        levels. Higher values may increase coverage but also FP risk.
                        Only effective when --enable-h26-self-attr-intermethod is true.
                        (default: 2, ENV: CAS_H26_MAX_HELPER_DEPTH)
```

## Flag Combinations

### Conservative Mode (Production)

```bash
python3 extract_python.py \
  --enable-h26-self-attr-intermethod false \
  --repo-root . \
  --out ./evidence
```

**Behavior:** H2.6 OFF, use H2/H2.5 only. Safest for production.

### Standard H2.6 Mode

```bash
python3 extract_python.py \
  --enable-h26-self-attr-intermethod true \
  --repo-root . \
  --out ./evidence
```

**Behavior:** H2.6 ON with depth=2. Balanced coverage/safety.

### Conservative H2.6 Mode

```bash
python3 extract_python.py \
  --enable-h26-self-attr-intermethod true \
  --h26-max-helper-depth 1 \
  --repo-root . \
  --out ./evidence
```

**Behavior:** H2.6 ON with depth=1. More conservative.

### Aggressive H2.6 Mode

```bash
python3 extract_python.py \
  --enable-h26-self-attr-intermethod true \
  --h26-max-helper-depth 3 \
  --repo-root . \
  --out ./evidence
```

**Behavior:** H2.6 ON with depth=3. Maximum coverage, higher FP risk.

## Interaction with Existing Flags

### `--emit-unresolved-self-attr`

H2.6 respects this flag for **unresolved** cases:

| `--emit-unresolved-self-attr` | H2.6 Resolved | H2.6 Unresolved |
|-------------------------------|---------------|-----------------|
| `true` | Edge emitted | Edge emitted |
| `false` | Edge emitted | Edge skipped |

### `--enable-h25-self-attr-noninit`

H2.5 and H2.6 work together:

| H2.5 | H2.6 | Resolution Order |
|------|------|------------------|
| OFF | OFF | H2 only |
| ON | OFF | H2.5 > H2 |
| OFF | ON | H2.6 > H2 |
| ON | ON | H2.5 > H2.6 > H2 |

**Priority:** H2.5 (method-local) > H2.6 (propagated) > H2 (class-level)

---

## Default Behavior Rationale

### Why H2.6 Default is `false`

1. **Safety First:** H2.6 introduces inter-method analysis with potential for
   false positives in edge cases (conflicts, cycles)
2. **Backward Compatibility:** v0.4.2 produces identical results to v0.4.1 by default
3. **Explicit Opt-In:** Users consciously enable inter-method propagation
4. **Audit-Friendly:** Conservative defaults reduce audit noise

### Why Depth Default is `2`

1. **Common Pattern:** Most helper chains are 1-2 levels deep
2. **Balance:** Covers common cases without excessive FP risk
3. **Performance:** Deeper chains have higher computational cost
4. **Empirical:** Based on codebase analysis patterns

## Validation

### Flag Parsing

```python
def _parse_bool(value: str) -> bool:
    return value.lower() in ("true", "1", "yes", "on")

def _parse_int(value: str) -> int:
    return int(value)
```

### Validation Rules

| Flag | Validation | Error |
|------|------------|-------|
| `--enable-h26-self-attr-intermethod` | Must be valid bool | "Invalid boolean value" |
| `--h26-max-helper-depth` | Must be int >= 0 | "Invalid integer value" |

### Edge Cases

| Case | Behavior |
|------|----------|
| Depth = 0 | H2.6 effectively disabled (no propagation) |
| Depth < 0 | Error: "Depth must be >= 0" |
| H2.6 ON, Depth = 0 | No H2.6 resolution (no propagation possible) |
| H2.6 OFF, Depth set | Depth ignored (H2.6 disabled) |
