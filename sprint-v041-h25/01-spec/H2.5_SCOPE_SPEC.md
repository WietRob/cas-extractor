# H2.5 Scope Specification — Intra-Method Non-`__init__` Self-Attr Resolution

**Feature-ID:** H2.5
**Sprint:** v0.4.1
**Status:** Specification (not yet implemented)

---

## Ziel

Erweitere H2-Resolution auf `self.attr = ClassName(...)` Assignments **außerhalb von `__init__`**, mit **intra-method write-before-use** Semantik.

---

## Pattern-Definition

### H2.5 Positive Pattern

```python
class Example:
    def setup(self):
        self.client = HTTPClient()  # H2.5 anchor (non-__init__)
        self.client.send()          # H2.5 resolved: HTTPClient.send
    
    def run(self):
        self.client.send()          # NOT H2.5 (cross-method) - stays unresolved
```

### H2.5 vs H2 Comparison

| Pattern | H2 (v0.3c) | H2.5 (v0.4.1) |
|---------|------------|---------------|
| `self.attr = Class()` in `__init__`, call in any method | ✅ Resolved | ✅ Resolved |
| `self.attr = Class()` in non-`__init__`, call in same method | ❌ Unresolved | ✅ Resolved |
| `self.attr = Class()` in non-`__init__`, call in different method | ❌ Unresolved | ❌ Unresolved |

---

## In Scope

| Pattern | Status |
|---------|--------|
| `self.attr = ClassName()` in non-`__init__` method | ✅ IN |
| `self.attr: Type = ClassName()` (AnnAssign) | ✅ IN |
| Write-before-use in same method body | ✅ IN |
| Last-assignment-wins within method | ✅ IN |
| Method-local tracking only | ✅ IN |

## Out of Scope

| Pattern | Status | Reason |
|---------|--------|--------|
| Cross-method propagation | ❌ OUT | Requires state analysis |
| Factory return inference | ❌ OUT | Requires interprocedural analysis |
| CFG/Branch-merge/Path-sensitivity | ❌ OUT | Too complex, high FP risk |
| Interprocedural state inference | ❌ OUT | Requires whole-program analysis |
| Cross-class propagation | ❌ OUT | Out of scope for v0.4.1 |

---

## Konfliktregeln

### Priority Order

1. **H2.5 method-local** > **H2 class-level (__init__)**
2. **Last assignment wins** within method scope

### Example

```python
class Example:
    def __init__(self):
        self.client = HTTPClient()  # H2 anchor
    
    def reconnect(self):
        self.client = WebSocketClient()  # H2.5 anchor (overrides H2)
        self.client.send()  # Resolves to WebSocketClient.send (H2.5 wins)
    
    def run(self):
        self.client.send()  # Resolves to HTTPClient.send (H2, no H2.5 in run)
```

## Unresolved/Skip Verhalten

### Relation zu H2.1 Flag

H2.5 wird durch das **bestehende** `--emit-unresolved-self-attr` Flag kontrolliert:

| Flag Value | H2.5 Resolved | H2.5 Unresolved |
|------------|---------------|-----------------|
| `true` | ✅ method_call | ✅ Edge emitted |
| `false` | ✅ method_call | ❌ Edge skipped |

**Wichtig:** Das Flag betrifft nur **unresolved** H2/H2.5 Fälle. **Resolved** dispatches werden immer emittiert.

### H2.5-Specific Flag (Optional)

Neues Flag für H2.5 Aktivierung:

```
--enable-h25-self-attr-noninit true|false
ENV: CAS_ENABLE_H25_SELF_ATTR_NONINIT
Default: false (für RC/GA-Sicherheit)
```

## Implementation Notes

### Data Structure

H2.5 braucht eine **method-local** Version von `self_attr_types`:

```python
# Current H2 (class-level, __init__ only)
enclosing_class.self_attr_types: dict[str, str]  # {attr_name: class_qname}

# New H2.5 (method-local, non-__init__)
method_local_self_attr_types: dict[str, str]  # {attr_name: class_qname}
```

### Resolution Order (Case 2d)

```python
# 1. Check H2.5 method-local first
if attr_name in method_local_self_attr_types:
    class_qname = method_local_self_attr_types[attr_name]
    # ... resolve to method_call
    
# 2. Fall back to H2 class-level
elif attr_name in enclosing_class.self_attr_types:
    class_qname = enclosing_class.self_attr_types[attr_name]
    # ... resolve to method_call

# 3. Unresolved or skip
else:
    if not emit_unresolved_self_attr:
        return None, "skip"
    return f"?.self.{attr_name}.{method_name}", "unresolved"
```
