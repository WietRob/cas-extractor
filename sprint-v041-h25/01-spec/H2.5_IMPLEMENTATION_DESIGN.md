# H2.5 Implementation Design — Intra-Method Non-`__init__` Self-Attr Resolution

**Feature-ID:** H2.5
**Sprint:** v0.4.1
**Status:** Implementation Design

---

## Design Overview

H2.5 erweitert die bestehende H2-Resolution um **intra-method** `self.attr` Tracking außerhalb von `__init__`.

### Key Design Principle

**Konservativ und sicher:** Nur wenn `self.attr = ClassName()` und `self.attr.method()` im **selben Methodenkörper** mit **write-before-use** auftreten, wird aufgelöst.

## H2.5 Design

### Data Structure

H2.5 braucht eine **method-local** Version von `self_attr_types`, ähnlich wie H1 `local_var_types`:

```python
# New: H2.5 method-local self-attr tracking
def _build_method_local_self_attr_types(
    func_node: ast.FunctionDef | ast.AsyncFunctionDef,
    local_classes: dict[str, "ClassInfo"],
    local_imports: dict[str, str],
    all_classes: dict[str, "ClassInfo"],
) -> dict[str, str]:
    """
    H2.5: Build mapping of self.attr names to their inferred class qnames.
    Only tracks: self.attr = ClassName(...) in current method (not __init__).
    Last assignment wins within method scope.
    
    Returns: {attr_name: class_qname}
    """
    attr_types: dict[str, str] = {}
    
    for node in ast.walk(func_node):
        if isinstance(node, ast.Assign):
            for target in node.targets:
                if (
                    isinstance(target, ast.Attribute)
                    and isinstance(target.value, ast.Name)
                    and target.value.id == "self"
                ):
                    attr_name = target.attr
                    class_qname = _infer_class_from_expr(
                        node.value, local_classes, local_imports, all_classes
                    )
                    if class_qname:
                        attr_types[attr_name] = class_qname
        elif isinstance(node, ast.AnnAssign) and node.value:
            if (
                isinstance(node.target, ast.Attribute)
                and isinstance(node.target.value, ast.Name)
                and node.target.value.id == "self"
            ):
                attr_name = node.target.attr
                class_qname = _infer_class_from_expr(
                    node.value, local_classes, local_imports, all_classes
                )
                if class_qname:
                    attr_types[attr_name] = class_qname
    
    return attr_types
```

### Resolution Logic (Case 2d Extension)

In `_resolve_call()` (Lines 383-543):

```python
def _resolve_call(
    func_node,
    ...,
    local_var_types: dict[str, str] | None = None,
    method_local_self_attr_types: dict[str, str] | None = None,  # NEW
    emit_unresolved_self_attr: bool = True,
) -> tuple[str | None, str]:
    
    # ... existing cases ...
    
    # Case 2d: H2/H2.5 - self.attr.method()
    if (
        isinstance(func_node.value, ast.Attribute)
        and isinstance(func_node.value.value, ast.Name)
        and func_node.value.value.id == "self"
        and enclosing_class is not None
    ):
        attr_name = func_node.value.attr
        method_name = func_node.attr
        
        # H2.5: Check method-local first (higher priority)
        if method_local_self_attr_types and attr_name in method_local_self_attr_types:
            class_qname = method_local_self_attr_types[attr_name]
            ci = all_classes.get(class_qname)
            if ci and method_name in ci.methods:
                return f"{ci.qname}.{method_name}", "self_attr_dispatch"
        
        # H2: Fall back to class-level (__init__)
        if attr_name in enclosing_class.self_attr_types:
            class_qname = enclosing_class.self_attr_types[attr_name]
            ci = all_classes.get(class_qname)
            if ci and method_name in ci.methods:
                return f"{ci.qname}.{method_name}", "self_attr_dispatch"
        
        # H2.1: Skip unresolved when flag is False
        if not emit_unresolved_self_attr:
            return None, "skip"
        return f"?.self.{attr_name}.{method_name}", "unresolved"
```

## Conflict Resolution

### Priority Order

1. **H2.5 method-local** (non-`__init__`, same method)
2. **H2 class-level** (`__init__` assignments)

### Example

```python
class Example:
    def __init__(self):
        self.client = HTTPClient()  # H2 anchor
    
    def reconnect(self):
        self.client = WebSocketClient()  # H2.5 anchor
        self.client.send()  # H2.5 wins → WebSocketClient.send
    
    def run(self):
        self.client.send()  # H2 wins → HTTPClient.send
```

## Risk Assessment

| Risk | Mitigation |
|------|------------|
| False positive resolution | Conservative: same-method only, no CFG |
| H2 regression | H2.5 checked first, then fallback to H2 |
| Performance impact | Minimal: only when flag enabled, reuses H1 pattern |
| Complexity | Low: mirrors existing H1 implementation |
