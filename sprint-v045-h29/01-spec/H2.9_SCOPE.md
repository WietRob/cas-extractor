# H2.9 Scope Specification — Enhanced Self-Attr Resolution Metadata

**Feature-ID:** H2.9
**Sprint:** v0.4.5
**Status:** Specification

---

## Ziel

Erweitere die H2-Resolution um **Auflösungs-Metadaten**: Für jeden self.attr.method() Call, protokolliere WIE und WARUM der Typ resolved wurde (oder warum nicht).

Dies ist **explAINABILITY** ohne die volle ResolutionEngine-Migration.

---

## Pattern-Definition

### H2.9 Resolution Metadata

```python
# Aktuelles Verhalten (v0.4.4):
# self.client.send() → HTTPClient.send (method_call)
# Keine Info darüber, WIE resolved

# Mit H2.9:
# self.client.send() → HTTPClient.send (method_call)
# resolution_metadata:
#   - heuristic: "H2.5"
#   - pattern: "self_attr_method_local"
#   - source: "TestExample.run:line 5"
#   - inferred_type: "module.HTTPClient"
```

---

## In Scope

| Pattern | Status |
|---------|--------|
| Add resolution_source to CallEntry | ✅ IN |
| Track which heuristic resolved (H1-H3) | ✅ IN |
| Track source location (file:line) | ✅ IN |
| Track inferred type | ✅ IN |
| Backward compatible (no behavior change) | ✅ IN |

## Out of Scope

| Pattern | Status | Reason |
|---------|--------|--------|
| Full resolution trace (like v0.5.0) | ❌ OUT | Requires engine migration |
| Multiple resolution paths | ❌ OUT | Too complex |
| Confidence scores | ❌ OUT | Not needed |

---

## Implementation

### CallEntry Enhancement

```python
# cas_extractor/models/evidence.py - Add optional field
class CallEntry:
    # ... existing fields ...
    resolution_source: str | None = None  # NEW: e.g., "H2.5:self.attr in __init__"
    resolution_detail: dict | None = None  # NEW: metadata dict
```

### CLI Flag

```
--enable-h29-resolution-metadata true|false
ENV: CAS_ENABLE_H29_RESOLUTION_METADATA
Default: false
```

### Metadata Format

```python
{
    "heuristic": "H2.5",           # Which heuristic resolved
    "pattern": "self_attr_method_local",  # Pattern matched
    "source_location": "file.py:10", # Where assignment found
    "inferred_type": "module.Class", # Type inferred
}
```
