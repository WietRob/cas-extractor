### Key Changes

1. **CLI-Flag**: `--emit-unresolved-self-attr true|false` mit Default `true`
2. **ENV-Support**: `CAS_EMIT_UNRESOLVED_SELF_ATTR=1|0`
3. **Priority**: CLI > ENV > Default
4. **Case 2d Skip**: Skip unresolved `?.self.<attr>.<method>` wenn flag=false

### Code-Auszüge

```python
# extract_python.py
def _parse_bool(value: str) -> bool:
    return value.lower() in ("true", "1", "yes", "on")

parser.add_argument(
    "--emit-unresolved-self-attr",
    type=_parse_bool,
    default=_parse_bool(os.environ.get("CAS_EMIT_UNRESOLVED_SELF_ATTR", "true")),
    help="Emit unresolved self.attr.method() calls (default: true)"
)
```

```python
# python_calls.py - Case 2d H2 skip
if not emit_unresolved_self_attr:
    return None, "skip"
return f"?.self.{attr_name}.{method_name}", "unresolved"
```

## Known Limitations

1. **Nur `__init__`-Zuweisungen** - Andere Methoden nicht berücksichtigt
2. **Keine Factory-Return-Inference** - `x = factory(); x.method()` bleibt unresolved
3. **Nur 3-part H2-Pattern** - `?.self.<method>` (2-part) wird nicht geskippt
