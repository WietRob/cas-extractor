# H2.1 Spezifikation — Feature-Flag `emit_unresolved_self_attr`

**Feature-ID:** H2.1  
**Status:** Spezifikation (nicht implementiert)  
**Ziel:** Metrikvergleichbarkeit steuerbar machen, ohne H2-Resolution zu verlieren

**Baseline Provenance:**
- Target repo: httpie/cli @ git:HEAD
- Extractor Stand: v0.3c
- Validation: `validation-v03c.txt`

---

## Zielbild

Feature-Flag für H2-Verhalten bei **nicht auflösbaren** `self.attr.method()`-Calls:

| Modus | Flag | Verhalten |
|-------|------|-----------|
| **Coverage** | `true` (Default) | Emit unresolved `?.self.<attr>.<method>` |
| **Comparability** | `false` | Skip unresolved H2-Fälle (kein Edge) |

**Wichtig:** Aufgelöste H2-Dispatches bleiben in **beiden Modi** erhalten.

---

## A) Implementierung

### A.1 Konfigurationsquelle

**Empfehlung:** CLI-Flag + Environment-Variable

```bash
# CLI
python3 extract_python.py --emit-unresolved-self-attr true|false

# Environment
export CAS_EMIT_UNRESOLVED_SELF_ATTR=1  # true
export CAS_EMIT_UNRESOLVED_SELF_ATTR=0  # false
```

**Priorität:** CLI > Environment > Default

### A.2 Default

**Empfehlung:** `true` (verhaltensstabil zu v0.3c)

```python
DEFAULT_EMIT_UNRESOLVED_SELF_ATTR = True
```

### A.3 Code-Änderungen

#### `extract_python.py`

```python
parser.add_argument(
    "--emit-unresolved-self-attr",
    type=lambda x: x.lower() in ("true", "1", "yes"),
    default=os.environ.get("CAS_EMIT_UNRESOLVED_SELF_ATTR", "true").lower() in ("true", "1", "yes"),
    help="Emit unresolved self.attr.method() calls (default: true)"
)
```

#### `python_calls.py` — `_resolve_call()` Anpassung

```python
# Aktuell (Case 2d H2):
if attr_name in enclosing_class.self_attr_types:
    class_qname = enclosing_class.self_attr_types[attr_name]
    ci = all_classes.get(class_qname)
    if ci and method_name in ci.methods:
        return f"{ci.qname}.{method_name}", "self_attr_dispatch"
return f"?.self.{attr_name}.{method_name}", "unresolved"

# Neu (mit Flag):
if attr_name in enclosing_class.self_attr_types:
    class_qname = enclosing_class.self_attr_types[attr_name]
    ci = all_classes.get(class_qname)
    if ci and method_name in ci.methods:
        return f"{ci.qname}.{method_name}", "self_attr_dispatch"
# Wenn Flag=false: skip statt unresolved
if not emit_unresolved_self_attr:
    return None, "skip"
return f"?.self.{attr_name}.{method_name}", "unresolved"
```
